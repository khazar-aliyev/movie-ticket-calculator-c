# 🎟️ Movie Ticket & Discount Calculator

A clean, beginner-friendly command-line utility written in **C** to calculate dynamic ticket pricing based on multi-variable criteria (age brackets and student identification status). 

This project demonstrates core programming foundations, including type management, input handling, boolean algebra, and conditional control flow.

---

## 🚀 Features
* **User Input Management:** Gathers user age, base ticket price, and student status securely via `scanf`.
* **Boolean Logic Evaluation:** Implements logical operators (`&&`, `||`, `!`) to check tier-based eligibility criteria (e.g., child, senior, or student discounts).
* **Conditional Control Flow:** Utilizes `if-else` statements to apply discounts dynamically and print clean, formatted outputs to the terminal.

---

## 💻 Tech Stack
* **Language:** C (C99 standard)
* **Compiler:** Apple Clang
* **Environment:** macOS, VS Code, Terminal

---
